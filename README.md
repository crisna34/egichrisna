# Egi Chrisna Agustian — Personal Website

A minimal, editorial-style personal website inspired by the clarity and restraint of skz.dev, with original content and visual identity.

## Stack
- Native HTML5, CSS3, and JavaScript
- Responsive, typography-led layout
- Light/Dark theme with saved preference
- Semantic markup, keyboard focus states, and reduced-motion support
- Basic SEO metadata, Open Graph, and Person structured data

## Local preview
Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment
Push changes to `main`. GitHub Actions deploys the static site to GitHub Pages.

## Content notes
Education details are based on the previous public site. Professional profile is intentionally high-level; employer, dates, detailed responsibilities, certifications, project case studies, and additional contact channels are omitted until verified and approved for public display.
