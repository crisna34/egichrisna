# Egi Chrisna Agustian — Personal Portfolio

Personal portfolio website deployed with GitHub Pages.

## Stack
- Native HTML5, CSS3, and JavaScript
- Responsive layout with mobile navigation
- Light/Dark theme with saved preference
- Intersection Observer for reveal effects and active section navigation
- Semantic markup, keyboard focus states, and reduced-motion support
- Basic SEO metadata, Open Graph, and Person structured data

## Local preview
Open `index.html` in a browser, or run a local static server from this directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment
Push changes to the `main` branch. GitHub Actions deploys the static site to GitHub Pages.

## Content notes
Education details are based on the previous public site. Professional profile is described at a high level; employer, dates, detailed responsibilities, certifications, project case studies, and additional contact channels are intentionally omitted until verified and approved for public display.
