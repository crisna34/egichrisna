# Egi Chrisna Agustian — Personal Website

Personal website built with native HTML, CSS, and JavaScript. The approved visual direction is a restrained, two-column editorial profile with warm typography, a profile photograph, and compact About / More sections.

## Features
- Responsive desktop and mobile layout
- Accessible mobile navigation
- Light / dark theme with saved preference and system-theme fallback
- Active section indication while scrolling
- Back-to-top control
- Keyboard focus states, skip link, and reduced-motion support
- Semantic HTML, SEO metadata, Open Graph, Twitter metadata, and Person structured data
- GitHub Pages deployment through GitHub Actions

## Local preview
Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment
Push changes to `main`. GitHub Actions deploys the static site to GitHub Pages.

## Content and privacy
Education details are based on the supplied profile information. Professional information is intentionally high-level. Employer names, exact employment dates, detailed responsibilities, certifications, and project case studies are not added until verified and approved for public display.
